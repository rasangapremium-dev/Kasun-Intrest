KASUN INTEREST TRACKER - ANDROID PROJECT

මෙය Android Studio හරහා APK එකක් Build කරගැනීමට සකස් කළ project එකකි. මෙතැනින් compile කර පරීක්ෂා කළ APK එකක් නොවේ.

APK එක Build කරන ආකාරය:
1. Computer එකක Android Studio install කරන්න: https://developer.android.com/studio
2. ZIP එක extract කරන්න.
3. Android Studio > Open > extract කළ KasunInterestTrackerAndroid folder එක තෝරන්න.
4. Gradle sync අවසන් වන තුරු රැඳී සිටින්න. Android SDK 35 අවශ්‍ය නම් Android Studio SDK Manager හරහා install කරන්න.
5. Build > Build Bundle(s) / APK(s) > Build APK(s) තෝරන්න.
6. Build සාර්ථක වූ විට app/build/outputs/apk/debug/app-debug.apk ගොනුව ලැබේ.
7. APK එක Phone එකට copy කර install කරන්න. Android එකෙන් අනතුරු ඇඟවීමක් ආවොත්, ඔබ විශ්වාස කරන APK එකක් බව තහවුරු කර පමණක් install කරන්න.

වැදගත්:
- App දත්ත phone එකේ app storage තුළ තබයි; app එක uninstall කළොත් දත්ත මැකෙන්න පුළුවන්.
- App එකේ Backup tab එකෙන් JSON backup එක නිතර download කර ආරක්ෂිත තැනක තබාගන්න.
- මුදල් ගනුදෙනු සඳහා භාවිත කිරීමට පෙර ගණනයන් ඔබේ මුල් sheet එක සමඟ පරීක්ෂා කරන්න.
- APK එක build කිරීමට computer එකක් අවශ්‍යයි. Android Studio project එකම APK එකක් නොවේ.
